PHP Backend Framework

Construisez des APIs
rapides & sécurisées

Babisoft Framework est un micro-framework PHP orienté API REST — routage expressif, ORM intégré, sécurité CSRF/CORS & gestion multi-modules prête pour la production.

Démarrage rapide Voir les fonctionnalités
Routes.php 
// Définir une route GET avec paramètre dynamique
App::route('GET', '/properties/{id}', function($id) {
    $rec = new PropertyTable();
    $rec->SetRange('id', $id);
    $rec->FindFirst();
    echo json_encode(['status' => 200, 'data' => $rec->toArray()]);
});

// Insertion via App::Insert()
App::route('POST', '/properties', function() {
    App::Insert('PropertyTable', getSecureJsonInput());
});

Fonctionnalités

Tout ce dont vous avez besoin

Un framework minimaliste avec les bons outils, sans la lourdeur des solutions entreprise.

⚡
Routage expressif

Routes GET / POST / PUT / DELETE avec paramètres dynamiques {id} résolus automatiquement via regex.

🗄️
ORM intégré

Tables, Codeunits et Enums inspirés de Microsoft AL. Validation de champs, Insert, FindFirst et SetRange natifs.

🔐
Sécurité CSRF & CORS

SecurityHeaders intégrés, tokenisation CSRF, gestion des origines autorisées et headers HTTP durcis par défaut.

🪪
Auth & Sessions

Gestion des sessions admin, profils utilisateurs, système d'autorisations granulaire et licences intégrés.

Architecture modulaire

Organisez votre code en modules indépendants — Tables, Codeunits, Enums — chargés via autoload Composer.

🧾
Génération PDF

FPDF et tFPDF embarqués pour générer quittances, contrats et rapports directement depuis vos Codeunits.

🌐
Client REST intégré

Système d'événements interne pour découpler la logique métier et déclencher des actions asynchrones entre modules.

Démarrage rapide

En production en minutes

Pas de configuration complexe. Clonez, configurez et déployez.

01

Cloner le projet

Récupérez le framework via Git et installez les dépendances Composer.

02

Configurer

Renseignez vendor/configs/configs.php — base de données, clés, origines CORS.

03

Déclarer vos Tables

Créez vos objets Table / Codeunit dans App/ selon la convention de nommage Babisoft.

04

Écrire vos routes

Ajoutez vos endpoints dans Routes.php avec App::route() et déployez.

Table & Codeunit — exemple 
// App/Tables/sysTable 0000001 Property.php
class PropertyTable extends Table {
    public string $TableName = 'properties';
    public int    $id;
    public string $title;
    public float  $price;
    public string $status = 'available';

    public function Validate(string $field, $value): void {
        match($field) {
            'price' => Assert($value > 0, 'Le prix doit être positif'),
            default => null
        };
        parent::Validate($field, $value);
    }
}

// App/Codeunits/sysCodeunit 0000001 PropertyMgt.php
class PropertyMgtCodeunit extends Codeunit {
    public function OnInsert(PropertyTable $rec): void {
        EventDispatcher::dispatch('property.created', $rec);
    }
}

Architecture

Structure du projet

Inspirée de Microsoft Dynamics 365 Business Central — claire, prévisible, extensible.

App/

  • Tables — modèles de données ORM
  • Codeunits — logique métier & triggers
  • Enums — types énumérés typés
  • Base system apps — modules système

vendor/meta/

  • Router.php — bootstrap & autoload
  • API/App.php — routeur & helpers
  • Database/ — couche PDO
  • Objects/ — classes de base (Table, Codeunit…)

vendor/security/

  • Security.class.php — headers durcis
  • check_security.php — audit de config
  • migrate_security.php — migrations de sécurité
  • sysTable csrfTokenizer — CSRF natif

vendor/Libs/

  • FPDF / tFPDF — génération PDF
  • ViewerJS — visualisation documents
  • APIRestCaller — client HTTP REST

À propos

Pourquoi Babisoft ?

Babisoft Framework est né du besoin de construire rapidement des APIs backend robustes sans la lourdeur de frameworks full-stack. Conçu pour des projets SaaS B2B en Afrique de l'Ouest, il privilégie la clarté du code, la sécurité native et une courbe d'apprentissage faible.

La convention de nommage inspirée de Business Central (Tables, Codeunits, Enums) favorise la cohérence à grande échelle et facilite l'intégration d'équipes back-office habituées à des ERP métier.
